# ⚡ Developer Portfolio

A sleek, dark modern developer portfolio built with React 19, Vite, and Vanilla CSS design tokens. Built using **GitHub Spec-Kit** for Spec-Driven Development (SDD).

## 🚀 Features

- **Linear / Vercel-Inspired Dark Aesthetic**: Deep obsidian theme with ambient radial lighting, subtle grid textures, and glassmorphism (`backdrop-filter: blur(16px)`).
- **Interactive Spotlight Cards**: Cursor-following border illumination across project cards.
- **Deep-Dive Case Studies**: Architectural breakdowns, quantifiable impact metrics, tech stacks, and live links.
- **Interactive Developer Console / Terminal**: Authentic monospace CLI with executable commands (`help`, `about`, `skills`, `projects`, `contact`).
- **Global Command Palette (`⌘K`)**: Fast keyboard-driven navigation across sections and social channels.
- **Centralized Data Model**: All portfolio information (projects, skills, bio, timeline) configured in `src/data/portfolioData.js`.
- **Spec-Kit Native**: Full specification lifecycle documented in `.specify/` and `specs/001-portfolio-showcase/`.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (Custom Properties, Grid, Flexbox, GPU-composited Keyframes)
- **Icons**: Lucide React
- **Typography**: Outfit & JetBrains Mono
